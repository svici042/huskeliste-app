# Huskeliste

React ir Vite užduočių sąrašo aplikacija.

## Paleidimas

Įdiekite priklausomybes ir paleiskite Vite serverį:

```bash
npm install
npm start
```

Atidarykite terminale parodytą adresą. Kitame įrenginyje tame pačiame tinkle naudokite Vite parodytą `Network` adresą.

Nenaudokite VS Code **Live Server** šaltinio `index.html` failui: jis netransformuoja JSX ir npm modulių. Statinei peržiūrai pirmiausia vykdykite:

```bash
npm run build
npm run preview
```

## Patikros

```bash
npm run lint
npm run build
```
